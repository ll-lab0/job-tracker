# 求职岗位跟踪（Job Tracker）

纯前端、零依赖的**单文件 HTML** 求职管理工具，帮你把投递全流程管清楚。数据存在你自己的浏览器，可选连接 GitHub 私有 Gist 跨设备同步。

## ✨ 三大亮点

- **数据看板**：总览 / 状态分布 / 周期趋势，一眼掌握投递全貌
- **JD 自动填充**：粘贴 JD 原文，自动提取公司、岗位、职责要点，少手工录入
- **跨设备同步**：基于 GitHub 私有 Gist，数据归你、免费、作者看不到

## 🚀 三种用法

1. **双击即用（最简单）**：下载 `index.html`，双击用浏览器打开。数据存本机，不联网也照用。
2. **在线 Demo**：https://ll-lab0.github.io/job-tracker （GitHub Pages，永久免费；国内访问偶慢，可下载文件本地跑）
3. **自部署**：Fork 本仓库，开启 GitHub Pages 或部署到任意静态托管（Vercel / Netlify / EdgeOne 等）。

## 🔗 跨设备同步（GitHub 私有 Gist）

1. 打开 https://github.com/settings/tokens
2. **Generate new token (classic)**，Note 随意填
3. 权限**只勾 `gist`** 这一项（其余别勾）
4. 复制生成的 `ghp_...` 令牌
5. 工具内点顶部「云同步」→ 粘贴令牌 → 保存并连接
6. 首次连接会自动在你的账户下创建**私有 Gist**；另一台设备粘贴同一令牌即连同一份备份

> 数据通过你的私有 Gist 同步，作者无法访问内容。令牌仅存你本机浏览器（含 10 年 cookie 回退，应对手机端清理），不上传任何第三方服务器。

## 📥 下载 / 导出说明

- 直接打开 `index.html`（非 iframe 嵌入）时，「导出」按钮可正常下载 JSON 备份。
- 若页面被嵌在 iframe 内（如某些预览壳），浏览器会禁用 `a.download`，此时工具自动改为「复制内容到剪贴板」，你手动粘贴保存即可。

## 🔄 同步机制与取舍

- **首连走合并**：本机 + 云端按记录 `更新时间` 逐条合并，**删除优先**（任一侧删除则合并结果为删除，避免跨设备删除被加回）。
- **连接后自动同步**：每次改动 800ms 防抖推送，且推送前先拉云端按 `updated` 合并，单方不会覆盖另一方。
- **取舍**：合并优先于「每设备独立」，默认全量快照自动同步；适合个人单用户多设备场景。

## 🔒 隐私与安全

- 无后端、无追踪、无第三方脚本。
- 所有字段经 HTML 转义，导入仅 `JSON.parse` 不 `eval`。
- 同步令牌仅本地存储，不上传作者服务器。
